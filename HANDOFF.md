# Fried Rice at Eddie's: handoff notes (menu, Tape 1, Tape 2)

Repo: FallGameDev/frae (GitHub Pages: fallgamedev.github.io/frae)

## Layout
- `index.html`: franchise menu (carousel of 4 games, VHS style). Save file picker (FILE 1-3, keys 1/2/3), remembered in localStorage `frae-file`. START opens `1/?file=N` or `2/?file=N`. Games 1 and 2 are unlocked (`GAMES` list).
- `1/index.html`: game 1, built by the tools below (do not edit by hand).
- `1/assets/`: `img/<group>/<name>.webp` (one finished picture each, pin in the middle, 2 px per game pixel), `snd/<group>/<name>.mp3`, fonts, `texts.json` (every word, for mods), loading-rice.webp. Same layout in `2/assets/`.
- Each game page is ONE plain HTML file with the hand-written code in `<script>`; there is no data block from the Scratch project. `names.js` (next to each game's code) lists which pictures/sounds exist; Tape 1's `words.js` holds the real text drawn on some pictures (mods change it in texts.json).
- `favicon.png/.ico` (rice bowl), `1/favicon.png/.ico` (Eddie), `2/favicon.png/.ico` (Eddie with a 2).
- `img/game1.png`, `img/game2.png`: menu card pictures.

## Building game 1
- Full build (re-renders all art from the Scratch project): `python3 tools/build_game1.py path/to/unzipped_sb3`
- Code-only rebuild (after changing JS/HTML only): `python3 tools/build_game1.py --code`
- The build describes every picture as layers (rooms, character files, words...), then `tools/flatten.py 1` paints each one into a single image file (headless browser, using `tools/legacy_layers.js`) and writes `tools/game/names.js` + `words.js` + `assets/texts.json`. `1/index.html` is just `game_shell.html` with the code files pasted into its `<script>`.
- Art pipeline: `tools/mods.py` (text sprites to real text, unused costumes), `tools/cameras.py` (empty rooms + separate character art), `tools/custom_night.py`, `tools/fanmade.py` (fan-made cast replaces FNaF characters).
- New phone calls and ringtone live in `tools/calls/` (night1-4.mp3, ringtone.mp3); the build copies them in.

## Hand-written game code (`tools/game/`)
- `pictures.js` (shared): loads `assets/img/<group>/<name>.webp` by name (`pic`, `picAt`, `hasPic`), draws them and their words, hit tests, mod file swaps (`MOD_FILES`), Smooth (interpolation between 30 Hz updates).
- `sound.js` (shared): sounds by name from `assets/snd/`, speakers with their own volumes, music/sound buses (music = `MUSIC_NAMES`), fadeOut.
- `game.js`: the Game class. Screens: title, night, custom, secret, black (+ overlays). Night logic: clock (90 s/hour), power, doors/lights, monitor + cameras, AI for Weddy/Cheddy/Endo/Eddie, phone + call banner, power out, jumpscares, 6 AM, endings, custom night (+ 1227 and 1987 codes). Save files: `frae1-save-fileN`.
- `secret.js`: the Dine In music video timeline.
- `achievements.js`: list of achievements, unlock(), Steam-style toast and list panel.
- `tools/ui.js` (shared by both tapes): settings, debug mode (H/P/G keys; blocks saving + achievements), mods, save file screen, Golden rate box (left arrow). Each shell sets `GAME_INFO` (storage key prefix `frae1` / `frae2`, mod template name, debug key help); Tape 1 uses the defaults.
- `tools/game_shell.html`: page, CSS, startup, main loop, input.

## Testing tips
- Serve the repo (`python3 -m http.server 8765`) and open `/1/?file=3`.
- `game.level = N; game.startNight()` jumps into a night; `game.debugInfo()` shows state.

## Tape 2 (`2/`)
Built from the FNaF 2 Scratch project (not in the repo, ~40 MB):
- Full build: `python3 tools/build_game2.py path/to/unzipped_FNAF_2_sb3`
- Code-only rebuild: `python3 tools/build_game2.py --code`. The full build ends with `tools/flatten.py 2` (pictures become plain image files, `tools/tape2/names.js`).
- Title song: `tools/tape2/title.mp3` (Beat Saber multiplayer lobby music). Ringtone shared from `tools/calls/`.
- Phone calls: the original FNaF 2 calls (nights 1-6) for now. The caller is "Fred" (purple circle, `drawPhone` in game.js).

### Art (`tools/tape2/`)
- `cast.py`: every room is an EMPTY picture (dark + flashlight-lit) and every character is a separate "pose" picture on top, measured by hand from where the FNaF character stood (`CAM_POSES`, `OFFICE_POSES`, boxes in costume pixels; `body` = whole character in the box, `head` = head fills the box). Also covers FNaF posters/plushies in rooms (`COVERS`), jumpscare frames, the cast standing (`Chars`), heads (`Heads`, custom night), office extras, prizes, title faces, 8-bit cast (`Pixel`).
- Who is who: the code ids are the FNaF 2 spots. Eddy = Freddy (tfreddy/wfreddy), Cheddy = Bonnie (tbonnie/wbonnie), Weddy = Chica (tchica/wchica), Withered Endo = Foxy, Meyg = Mangle. (Tape 1 still has Weddy in Bonnie's spot and Cheddy in Chica's; ask Aidan before changing it.)
- Characters are drawn by the game at runtime (`tools/tape2/actors.js`), never baked into pictures. Rooms/office are empty pictures; `tools/tape2/poses.js` (written by `cast.py` from its hand-measured tables) says where each character stands, how big (body/head mode) and how dark. Each character is its 3D model from `models/` (names in `ACTOR_FILES`; three.js in `2/lib/three`, loaded with an importmap only if a model exists; rendered once at load, standing + lunge, then drawn as flat pictures) or else its 2D drawing (`Chars` group from `tools/tape2/characters/<role>.svg`, or stand-ins). Meyg (the Mangle role) = Toy Endo in a broken pose until a `meyg` model exists. The toys have three faces (models/faces, painted onto the head texture by tools/face_toys.py): calm "stand" (stage, newspapers, custom night, plushies), creepy "creep" (cameras, hall, vents, title), scary "lunge" (office, jumpscares). Loading screens: the spinning rice bowl.
- `extras.py`: the camera map with no lit button + each lit button.

### Game code (`tools/tape2/`, shares `tools/game/pictures.js` + `sound.js` + `tools/ui.js`)
- Weddy's face plate: off the stage (kinds creep/vent/hall/lunge and her 3D jumpscare) her face is a glitching black box like Honcho in DOORS (`FACE_OFF`, `drawRedaction` in actors.js). The face spot comes from the 3D model: `findFace` (front of the Head material, kept in the Head bone's space) and `faceAt` (projected per rendered frame, carried as `sprite.face`, `Actors.scareFace` for live scares).
- The mask: Aidan's `tools/tape2/mask.svg` (`aidan_mask()` in build_game2.py) replaces Sprite3 "88" (mask on) and the 6 Sprite4 costumes (it slides up onto your face, `MASK_SLIDE`). The old Freddy mask recolor is off (`MASK_SPRITES` empty).
- `game.js`: title (New Game / Continue / 6th Night / "It's still dark."), newspaper (Aidan's picture tools/tape2/newspaper.png, picture Newspaper/page), night intro, the night (70 s per hour), mask (Q / bottom-left bar), cameras (E / bottom-right bar), flashlight (hold Space/F/Ctrl or click-and-hold) with battery, vent lights (A/D or hold the LIGHT buttons), music box on CAM 11, AI for 10 characters (`PATHS`, `DETOURS`, `NIGHT_AI`), office visits (mask in time), Withered Endo in the hall (flash him away; if he lunges he does not kill you, he starts the stare minigame: `startStare/updateStare/drawStare` in game.js, Aidan's drawing `tools/tape2/endo_stare.png` split by `split_stare()` in cast.py into Stare/ring, Stare/ring-red and Stare/head. The head shrinks, taps pump it, keep it between 0.93 and 1.14 of the outline; `danger` fills while outside (full = his jumpscare), survive `need` = 6 + level*0.2 s and he goes back to cam 8; the night waits meanwhile), Puppet, Golden Eddie, BB disabling lights, Meyg on the ceiling, phone, 6 AM, endings (drawn by the game), Deaths: 1 in 3 go to a minigame (any jumpscare setting), picked by the killer (`MINIGAME_FOR`: Withered Endo/Meyg = run, both Eddys = cake, Puppet = gifts, others random). GET READY minigame: the runner is Aidan's Endo drawing (`tools/tape2/minigame_endo.png`, made 8-bit as Pixel/runner in cast.py) and the last run is a huge 8-bit fire (`drawPixelFire`, no purple man or children); the title right after it says "Eddies Riceria" with the crying rainbow guy (`tools/tape2/riceria_crying.png`, picture Riceria/crying, `game.riceria` flag, once); custom night with 12 presets (the last, "F*CK NO!", is everyone on 20 with no prize) and desk prizes; each portrait gets Aidan's red star (`tools/tape2/eye_star.png`, picture Custom/star) over its right eye, alpha = level/13 (`EYE_SPOT` in game.js holds each portrait's eye spot). Save files: `frae2-save-fileN` (beat5/beat6/beat420 = the three stars, same as Tape 1 so the menu shows them).
- `minigames.js`: death minigames (Take Cake, Give Gifts Give Life, Endo Go! Go! Go!).
- `achievements.js`: Tape 2 achievement list.
- `shell.html`: page, keys (hold keys for flashlight / vents / 8-bit movement).
- Every word the game draws goes through `W("group", "text")`; the build collects them into texts.json for mods.

## 3D models (`models/`)
- Every character model goes straight in `models/` (glb/gltf/fbx/obj, named like `withered_eddy.glb`); the game picks it up with no build. `.blend` -> `.glb`: `python3 tools/convert_models.py`. Toys: `models/toys_rigged.blend` + `toy_*.glb/.fbx`, rebuilt with `python3 tools/rig_toys.py models/basemodel.blend models`. See `models/README.md`.
- Skeletons and animations (actors.js): models with the base skeleton (Hips, Chest, Head, UpperArm.L/R, Leg.L/R) use MODEL_POSES (bone turns). Any other skeleton follows the SET RIG: `setRigPart` matches bones by name (Mixamo, Rigify DEF-, Bip01, VRoid J_Bip, base names), `findSetRig` keeps the bone nearest the body per part, and `poseSetRig` points chest/head/upper arms/thighs along `SET_RIG_POSES` directions, so any rig gets the same stand/lunge/broken poses. A model with an animation (named idle/loop, else the first) plays it while standing: `renderAnimation` renders up to 30 frames (12 fps, 520 px tall, standing pose underneath) cut to one shared box; `Actors.get` picks the frame by time.
- Mod storage has no size limit: the mod list and state stay in localStorage (`<key>-mods`, `<key>-mods-state`), the files go to IndexedDB `<key>-mods-files` (key `<modId>/<path>` -> Blob, `ModFiles` in ui.js) and the page asks for persistent storage. Old 5 MB mods (data: URLs in localStorage) move over by themselves (`ModDB.upgrade`).
- Mods have no limits (both tapes, ui.js): every file in a mod is kept. Game files are replaced as before; new pictures `img/<folder>/<name>.png` and sounds `snd/<folder>/<name>.mp3` are added to PICTURE_NAMES/SOUND_NAMES (`addNewModFiles`); `mod.js` and any .js run as normal <script>s after the files are in place and before loading (`runModScript`; bottom mod first). Toolbox `FRAE`: file(), image(), onReady() (run by the shell before boot), after/before/replace(obj, fn). Loading a mod with code asks for confirmation. The template has a commented mod.js. GitHub mods take every file.
- Mods (Tape 2): a mod can also have `models/<name>.glb|gltf|fbx|obj` and `characters/<name>.png|webp|jpg|svg` (names from `ACTOR_FILES`, or the role id). Order: mod model > mod drawing > game model > game drawing. The template ships the game's models and the drawings of characters without a model, plus a README.txt with the names. Code: `actorModFile`/`addActorTemplate` in ui.js, `modActorFile` in actors.js.
- Office: Aidan's own office renders in `tools/tape2/office/` (000 dark, 010 hall light, 100 left vent, 001 right vent; saved 3 px per game unit, `big` in flatten.py). The old FNaF desk + fan are hidden (his office has its own). Hall/vent spots measured in the FNaF office are moved into his door and vents by `office_spot()` in cast.py (`NEW_VENT_HOLE`, `NEW_HALL`).
- Withered look: `tools/tape2/withered.py` tears up the withered drawings at build time (holes with endoskeleton struts and wires, bitten ears, grime, head knocked crooked at the neck) plus one misconfiguration each: Withered Eddy an empty eye socket, Withered Weddy no face (black void, endo eyes, teeth), Withered Cheddy a dropped jaw, Withered Endo a ripped-open chest. Saved as assets/characters/<role>.png. The mask is an Eddy mask: `eddy_mask()` in build_game2.py recolors Sprite3/Sprite4 (brown -> yellow, fur -> cream).
- Updating a toy from Aidan's .blend: `python3 tools/update_toy.py file.blend "Toy Weddy"` then `python3 tools/face_toys.py` (attaches loose parts / metaballs to the Chest bone, re-exports with faces).
- The Puppet is Aidan's drawing `tools/tape2/characters/puppet.png` (used exactly as drawn, white outline is on purpose; PNG drawings are supported by `Char._from_png`). Its 8-bit minigame version gets a grey outline so it shows on black. Toy Weddy's chest wobbles through a 3x3x3 lattice ("Toy Weddy Chest Lattice", parented to the Chest bone, Soft Body on the lattice with the back row pinned; the chest mesh has Armature then Lattice modifiers) in toys_rigged.blend (Blender only: .glb/.fbx and the game's pre-rendered poses can't carry it).
- Toy animations (`tools/animate_toys.py`, then `tools/face_toys.py` exports them as NLA tracks): Crawl (lying in a vent, shown on cams 5/6 and the office vents, kind "vent"), Walk (lurching, shown in the hall: office hall + cam 7, kind "hall"), Idle (2 s loop: breathing, head tilt, arm sway; Meyg twitches) and Scare (Eddy lunges with a 360 head spin, Weddy lunges chest-first with a Bust bone wobble, Cheddy rises and strangles, Meyg covers the camera with her hand). The whole toy moves with the Root bone. In the game: idle is pre-drawn (10 frames per loop, 440 px) for stand/creep; Weddy's chest follow-through is baked onto her Bust bone in every animation; the title close-up is its own sharp still (kind "title"); posters, plushies, newspapers, menu and custom night portraits hold still (`still: true`); jumpscares are drawn LIVE with three.js (`Actors.scareFrame`, kept alive only if a model has a Scare clip; camera at the player's seat), over the dark office with a growing shake.
- Sounds: no camera hum, no camera-switch static, no flashlight buzz and no vent light hum (removed from game.js). The office fan is Aidan's fan noise + rain mixed into a 90 s seamless loop (`tools/tape2/fan.mp3`, swapped in for Fansound/fansound by build_game2.py).
- Lag fixes: pictures are decoded while loading, then every picture and character is drawn once (tiny, under the cover) so the graphics card has them before play; 2D characters are measured while loading (measuring mid-night with getImageData stalled the game once characters started moving); no TV static anywhere in Tape 2 (title, cameras, death: drawStatic only paints black at full strength); opaque canvas (`alpha: false`); drawing capped at 60 per second; imageSmoothingQuality "low" ("high" was re-filtering every scaled picture each frame); HUD text shadow is a 1px offset copy, not shadowBlur; darkening uses a cached black copy instead of `ctx.filter`; the canvas is capped at 960 device px wide (2 per game pixel); long animations are saved at half size (`half` lists in `tools/flatten.py`, `HALF_SIZE_GROUPS`). Decoded pictures: Tape 1 about 330 MB (was 550), Tape 2 about 130 MB (was 550).
